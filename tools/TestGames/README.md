# Test games

A stand-in "game" for trying c0n50le without real games: a full-screen window that shows its own name and quits with
Esc. `Make-TestLibrary.ps1` copies it as *Pokemon Pokopia*, *Control Resonant*, *FIFA 27* and *GTA 6* into
`library/` (ignored by git). Pick that folder in System → Library → Games folder.
